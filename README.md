# VEC Rule Scenario Trainer

An offline, no-dependency quiz for practicing the Virtual Embryo Challenge rules that are easy to misread in real workflows: external-data boundaries, the Agent Team configuration lock, evidence requirements, P3 submission limits, and the Generality Award.

It is designed for new and returning participants who want to check a concrete scenario before they commit a data source, lock a run, or spend a scarce submission attempt. Every answer includes a short explanation and links to the official rule or data page.

## Use

Open [`index.html`](index.html) in any modern browser. Choose a topic or run all scenarios. The app works offline after download, stores no answers, and sends no data. There is no build step, package installation, login, analytics or server.

## Scope and maintenance

This is a learning aid built from the official pages linked below, not an organiser ruling. The rules can change; the snapshot was checked on **14 October 2026**. Always open the current official page for a consequential edge case. The quiz links directly to the source pages and identifies the relevant rule section in each explanation. It contains 30 scenarios: 12 about data eligibility, 8 about Agent Team work, 6 about phases and submissions, and 4 about the Generality Award.

The current scenario set covers:

- exact versus protected external-data stage boundaries for T1, T2 heart, and T2 embryo;
- the requirement to disclose external sources and remove protected cells from mixed-stage resources;
- genotype-level exclusion for Task 3;
- the Agent Team lock, crash/restart distinction, run selection, and required evidence;
- P3 attempt limits, format checks, daily quotas, and final ranking;
- the shared-architecture requirement for the Generality Award.

## Official sources
